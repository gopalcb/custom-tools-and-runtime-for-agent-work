Component Catalog and Orchestration Details

This page documents the available diagram-builder components and how they fit together. The builder turns clear YAML into clean HTML diagrams.

Open the generated diagram page or inspect the source YAML.

Main Diagram Types

  • flow: steps from top to bottom.
  • tree: file, ownership, or nested structure.
  • event_bus: sources feeding a hub and producing outputs.
  • component: one reusable unit.
  • component_stack: a larger picture made from reusable units.
  • component_gallery: a generated guide to available architecture components.

Architecture Components

Use vertical architecture components when the idea moves from top to bottom. Use node-only above and below compound components when those components already own their connector lines.

Orchestration

The orchestration is intentionally small: YAML declares the diagram, validation checks it, rendering creates HTML, and CSS provides stable geometry, colors, connectors, and animation.

YAML -> validation -> HTML -> CSS-rendered diagram

Composition Rule

Choose the shape that matches the thought. Use flow for sequence, tree for nesting, event bus for runtime movement, component stacks for composed systems, horizontal arrows for peer relationships, and square nodes for states or small concepts.
